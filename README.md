# 听荐

AI 无线耳机评论决策助手

商品页上的星级和评论摘要能说明总体口碑，却很难回答一个更具体的问题：这款耳机适合我的使用场景吗？

听荐从这个问题出发。用户先说明通勤、视频会议、运动或长时间佩戴等需求，系统再从当前商品评论中寻找相关的正反证据，给出适配判断，并保留原评论供用户核验。

> 当前版本是规则化概念原型，用于验证需求表达、证据展示和商品比较的产品逻辑。

## 问题背景

同一款耳机可能适合听音乐，却不适合通勤或会议。总体评分把不同用户和场景混在一起，统一评论摘要也容易丢失条件、冲突观点和具体风险。

项目使用 14,811 条公开移动配件评论进行探索性分析，并参考 AmazonQA 公开样本设计证据展示。分析关注三个问题：

- 总体评分是否掩盖具体风险
- 不同评论主题的提及量和负面占比是否一致
- 高星评论中是否仍然包含连接、音质或舒适度问题

这些分析用于判断产品机会，不用于评价或推荐某个真实商品。两个公开数据源也没有进行商品级拼接。

## 用户需求调研

项目已发布第一轮匿名用户需求问卷，面向过去一年内购买或认真比较过无线耳机的用户。问卷先了解用户从产生购买需求、搜索信息、比较商品到最终决策的完整流程，再识别其中的信息筛选、观点冲突、场景匹配和商品比较问题；最后介绍“听荐”的产品概念，收集用户对功能优先级、使用阶段、信任顾虑、使用意愿和产品入口的反馈。

## 产品流程

1. 用户从商品详情页进入“AI 帮我判断”。
2. 选择使用场景、关注维度和排除条件。
3. 检查并修改系统解析出的需求标签。
4. 查看较匹配、不确定、较不匹配或无法判断四档结果。
5. 回到英文原评论核验正反证据和中文摘要。
6. 沿用同一组需求比较两款商品。

## 产品规则

### 判断和证据分开

“是否适合”与“结论有多可靠”是两个问题。报告分别展示适配判断和证据强度，避免把评论数量多理解成商品一定适合。

### 不使用未经校准的百分比分

当前版本使用“较匹配、不确定、较不匹配、无法判断”四档结果。没有标注集和校准之前，类似“78% 匹配”的数字会制造不必要的精确感。

### 结论可以回到原评论

用户可以查看英文原评论、中文摘要以及支持和反对片段。缺少验证购买、有用票等字段时，页面显示“数据源未提供”，不根据空值推断评论质量。

### 允许没有推荐结果

证据不足、观点冲突或两款商品不可比时，系统可以返回“不确定”或“无明确胜者”，而不是强制完成推荐。

## AI 在流程中的职责

AI 负责需求解析、主题识别、观点提取、相关证据检索和中文总结。商品名称、评分、评论数量和英文原文等事实字段应从数据中读取。引用校验失败或证据不足时，系统需要降级。

## 当前状态

原型没有接入真实模型、后端或电商商品库，部分结果使用固定演示案例。用户需求问卷已经发布并处于回收阶段，真人访谈和可用性测试尚未正式完成，因此项目暂不包含任务效率、理解率或业务增长等结果数据。

下一步计划是完成问卷回收和样本清理，提炼用户选购旅程、核心痛点与需求优先级；随后开展 3 至 5 位用户的探索性测试，验证需求确认、证据理解和商品比较流程，再决定是否接入真实商品级评论数据。
